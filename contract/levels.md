# Captured contracts

[source.json](source.json) pins the original SpeakUp revision and runtime.
[dto.ts](dto.ts), [view.ts](view.ts), and [source](source) are frozen reference inputs.
[fixtures.json](fixtures.json) is generated by executing the captured TS mappers and Go serializer.

- Compare JSON structure for DTO mappings, avatar strings and signaling payloads.
- Normalize missing memo fields to empty strings at the adapter.
- Do not require MoonBit class instances to have plain-object prototypes or identity.
- Validate positive signed 32-bit IDs before conversion. Conversation clocks use safe integer epoch milliseconds; legacy display dates remain strings.
- Keep media and upload bytes in platform adapters.

Run `npm run fixtures` from the repository root. Expected outputs come from the frozen source,
not the current implementation. [Message](message/README.md) and [frontend](frontend/README.md)
contracts cover their own pinned revisions. Deliberate protocol, authentication, schema and UI
changes belong in [migration.md](../docs/migration.md).
