# Frontend source oracle

Pinned source: `3561429e55a22d400702bf5df694670c52f2e721`
(Node 24.13.0, MoonBit 0.10.14, TypeScript 5.9.3).

| File | Contract |
| --- | --- |
| `voiceCall.source.ts`, `ActivityLayout.source.tsx` | Frozen resource-owning controllers; reference source only |
| `httpClient.ts`, `errorUtils.ts` | Frozen HTTP adapter and error display |
| `projections.source.js` | Executable extracts for notification text/destinations and microphone projections |
| `fixtures.json` | Outputs generated by executing the extracts and error helper |

`npm run fixtures` uses the checked-in source and works without Git history.
To re-extract projections, run `node scripts/capture-frontend.mjs --capture-source`
in a checkout containing the pinned revision. Never recapture from current HEAD.

[frontend-projections.test.mjs](../../tests/frontend-projections.test.mjs) compares generated
MoonBit JS with these outputs. The old HTTP adapter has optional tests under
[tests/oracles](../../tests/oracles), run by `npm run test:oracle-http`.
The current transport is tested separately in [transport.test.mjs](../../tests/transport.test.mjs).

These fixtures establish targeted source parity. Cancellation, stale responses and bounded queues
use controller tests; DOM wiring and real audio use browser tests.
They do not prove equivalence of every async ordering. Record intentional differences in
[migration.md](../../docs/migration.md); do not rewrite the oracle to match the implementation.
