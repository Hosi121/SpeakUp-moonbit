# Frontend controller migration oracle

Source: `3561429e55a22d400702bf5df694670c52f2e721` (Node 24.13.0,
MoonBit 0.10.14, TypeScript 5.9.3).

- `voiceCall.source.ts` and `ActivityLayout.source.tsx` are verbatim snapshots
  of the two resource-owning controllers before replacement. They are reference
  source, not modules imported by the application.
- `httpClient.ts` and `errorUtils.ts` are verbatim snapshots of the original HTTP
  adapter. The five existing `tests/http-client.test.mjs` cases execute this
  frozen oracle. The new adapter has its own real HTTP tests in
  `tests/transport.test.mjs`; the oracle tests alone do not establish parity.
- `projections.source.js` contains executable source extracts for notification
  destinations/text and microphone levels/speaking thresholds. It was extracted
  using the TypeScript AST, not reimplemented from the new MoonBit code.
- `fixtures.json` is generated by executing those extracts and the original
  error display helper: 10 notifications, 5 audio inputs and 7 error payloads.
  `tests/frontend-projections.test.mjs` compares the actual generated MoonBit JS
  to those results. Expected values are not handwritten.

`npm run fixtures` regenerates expected output from these checked-in sources,
so CI does not need Git history. To recapture the projection source from the
pinned commit, use `node scripts/capture-frontend.mjs --capture-source` in a
checkout containing that revision. Do not recapture it from the current HEAD.

Existing browser/navigation tests remain the observable behavior contract for
all screens. Their original source remains available at the pinned commit,
including forms, HTTP payloads and messages.

New deterministic port tests supplement this oracle with cancellation, stale
responses and bounded signal queues. Deliberate corrections are recorded in
[the migration record](../../docs/frontend-controllers.md); the captured source
is never rewritten to agree with the new controller. This is targeted source
parity and browser regression coverage, not exhaustive equivalence of all
asynchronous event interleavings.
